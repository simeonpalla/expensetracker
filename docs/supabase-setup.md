# Supabase setup

The app needs a Supabase project with email/password auth, five tables, and
Row Level Security. The Netlify functions call Supabase with the **anon key
plus the signed-in user's JWT**, so RLS is the authorization boundary — if
RLS is off, the (public) anon key can read everything. Do not skip step 3.

## 1. Auth

- Authentication → Providers → Email: enabled.
- "Confirm email" is supported either way: with confirmation on, signup
  returns a "check your email" state; with it off, users are signed in
  immediately.

## 2. Tables

Reference DDL (matches what the functions read/write; adjust types if your
existing tables differ — this file documents the expected shape):

```sql
create table public.transactions (
  id               bigint generated by default as identity primary key,
  user_id          uuid not null references auth.users (id) on delete cascade,
  type             text not null check (type in ('income', 'expense')),
  amount           numeric not null check (amount > 0),
  category         text not null,
  transaction_date date not null,
  payment_to       text,
  payment_source   text,
  source_details   text,
  description      text,
  is_recurring     boolean not null default false,
  created_at       timestamptz not null default now()
);

create table public.categories (
  id         bigint generated by default as identity primary key,
  user_id    uuid not null references auth.users (id) on delete cascade,
  name       text not null,
  type       text not null check (type in ('income', 'expense')),
  icon       text,
  created_at timestamptz not null default now()
);

create table public.time_logs (
  id               bigint generated by default as identity primary key,
  user_id          uuid not null references auth.users (id) on delete cascade,
  activity         text not null,
  category         text not null,
  start_time       timestamptz not null,
  end_time         timestamptz not null,
  duration_seconds integer not null check (duration_seconds >= 0),
  date             date not null,
  notes            text,
  created_at       timestamptz not null default now()
);

create table public.workouts (
  id               bigint generated by default as identity primary key,
  user_id          uuid not null references auth.users (id) on delete cascade,
  date             date not null,
  workout_type     text not null,
  start_time_str   text,
  raw_text         text,
  exercises        jsonb not null default '[]',
  duration_minutes integer,
  created_at       timestamptz not null default now()
);

create table public.active_timers (
  id             bigint generated by default as identity primary key,
  user_id        uuid not null unique references auth.users (id) on delete cascade,
  activity       text not null,
  category       text not null,
  start_epoch_ms bigint not null,
  date           date not null,
  created_at     timestamptz not null default now()
);
```

`active_timers.user_id` must be UNIQUE — the start-timer endpoint upserts on
it (one active timer per user).

Useful indexes:

```sql
create index if not exists transactions_user_date_idx on public.transactions (user_id, transaction_date desc);
create index if not exists time_logs_user_date_idx    on public.time_logs (user_id, date desc);
create index if not exists workouts_user_date_idx     on public.workouts (user_id, date desc);
```

## 3. Row Level Security (required)

Run [`supabase/migrations/0001_rls_policies.sql`](../supabase/migrations/0001_rls_policies.sql)
in the SQL editor. It is idempotent: enables RLS on all five tables and
creates select/insert/update/delete policies scoped to
`auth.uid() = user_id`.

Verify under **Authentication → Policies**: every table should show RLS
enabled with 4 policies.

## 4. Keys

Settings → API:
- `SUPABASE_URL` and `SUPABASE_ANON_KEY` go into Netlify env vars and local
  `.env` (see `.env.example`).
- The **service-role key is not used** by this app. If it was ever configured
  in Netlify, remove it; if it may have leaked, rotate it here.
